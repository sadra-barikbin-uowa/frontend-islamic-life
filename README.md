# ICITIC 2026 — Conference Website

موقع المؤتمر الدولي الأول لتقنيات المعلومات والحوسبة الذكية
كلية علوم الحاسوب ونظم المعلومات — جامعة وارث الأنبياء

## التقنيات
React 18 + TypeScript + Vite + Tailwind CSS + Framer Motion + Lucide React + React Router

## التشغيل محليًا
```bash
npm install
npm run dev
```
يفتح على http://localhost:5173

### تشغيل استقبال البحوث
تعمل نافذة تقديم البحوث عبر endpoint خادمي مستقل حتى لا تظهر بيانات SMTP في المتصفح.
انسخ `.env.example` إلى `.env` وضع بيانات صندوق SMTP على الخادم فقط، ثم شغّل الخادم في نافذة طرفية ثانية:

```bash
npm run server
```

أثناء التطوير، يمرّر Vite طلبات `/api` إلى الخادم على المنفذ 3001. في الإنتاج يجب نشر
`server.cjs` خلف نفس النطاق أو عبر reverse proxy، مع ضبط متغيرات البيئة نفسها.

## البناء للإنتاج
```bash
npm run build
npm run preview
```
سيُنشأ مجلد dist/ جاهز للرفع على أي استضافة (Vercel, Netlify, أو استضافة الجامعة).

## التخصيص
- كل نصوص الموقع (عربي/إنجليزي) موجودة في ملف واحد: `src/i18n/content.ts`
- الألوان والخطوط: `tailwind.config.ts`
- تبديل التاريخ الفعلي للعد التنازلي: `src/components/Countdown.tsx` (متغير TARGET)
- استبدال خريطة Google Maps بموقع الجامعة الدقيق في `src/components/Venue.tsx`

### خط Somar Sans
ضع ملفات الخط في `public/fonts/somar-sans/` بالأسماء الموضحة داخل
`public/fonts/somar-sans/README.txt`. إلى حين إضافتها سيعمل الموقع بخط احتياطي
مشابه تلقائيًا دون أي كسر بالتصميم.

### صور الـ Hero (السلايدر)
ضع 3 صور في `public/images/hero/` بنفس الأسماء: `hero-1.jpg`, `hero-2.jpg`, `hero-3.jpg`
(المقاس المقترح 1920×1080). السلايدر يتبدل تلقائيًا كل 5 ثوانٍ، وبه سهم للتنقل اليدوي.
حاليًا الصور صور مؤقتة (Placeholder) تشير إلى مكانها — استبدلها بنفس الاسم مباشرة.

### روابط الأرشيف
أضف روابط المواقع القديمة في `src/config/archiveLinks.ts` — تظهر تلقائيًا
ضمن زر "الأرشيف" في الـ Navbar (وفي القائمة الجانبية على الجوال).

### الجهات الداعمة (Sponsors)
عدّل القائمة من `src/config/sponsors.ts`. لإضافة شعار: ضع صورة الشعار في
`public/images/sponsors/` ثم اكتب مسارها في حقل `logo`. تم بالفعل إضافة
العتبة الحسينية المقدسة وجامعة وارث الأنبياء بصور مؤقتة تحتاج استبدال فقط.

### ملاحظة
تم استبدال "جامعة واسط" بـ "جامعة وارث الأنبياء" في كل النصوص. عنوان القاعة
لا يزال يذكر "الكوت، محافظة واسط" — إن كان مقر جامعة وارث الأنبياء الفعلي في
كربلاء، حدّث العنوان يدويًا من `src/i18n/content.ts` (قسم venue وcontact).
